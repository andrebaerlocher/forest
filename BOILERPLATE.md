# Project Template & Boilerplate Reference

This document preserves the original template initialization and setup commands generated by [`sv`](https://npmjs.com/package/sv) when creating this project.

## Creating a Project

```sh
# create a new project in the current directory
npx sv create

# create a new project in my-app
npx sv create my-app
```

## Recreating This Project Configuration

To recreate this exact project with the same configuration and tools (SvelteKit library, TypeScript, Storybook, MCP integration, Bun):

```sh
bun x sv@0.16.3 create --template library --types ts --add storybook mcp="ide:other+setup:remote" --install bun ./
```

## Deploying Showcase App

> To deploy your showcase app, you may need to install an [adapter](https://svelte.dev/docs/kit/adapters) for your target environment.
